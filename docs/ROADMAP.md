# Что предстоит сделать

Этапы ориентировочные, порядок может меняться. Отметки: `[ ]` — не начато,
`[~]` — в работе, `[x]` — готово. Текущее состояние — в [STATUS.md](STATUS.md).

## v0.2 — Производительность и типы заявок

- [x] **Интрузивный список на ценовом уровне** → отмена внутри уровня за `O(1)`
      (узлы в слабе-арене со списком свободных слотов; снят прежний `O(n)` скан).
- [x] **Команда `Modify` / amend** — изменение цены/количества; смена цены или
      увеличение объёма теряет временной приоритет, уменьшение — сохраняет.
- [x] **Post-only** — отклонять заявку, если она немедленно пересекла бы спред (maker-only).
- [x] **Stop / stop-limit** — отложенные заявки, активируемые по триггерной цене
      (по цене последней сделки; срабатывание каскадное, событие `Triggered`).
- [x] **Iceberg** — видимая (peak) и скрытая (reserve) части объёма; при исчерпании
      видимой части peak доливается из резерва в хвост уровня (теряя приоритет).
- [x] Пул переиспользуемых аллокаций в матчинге (слаб со списком свободных слотов;
      убран `Vec` под исполненные id).

## v0.3 — Надёжность и реплей

- [x] **Журнал событий (event sourcing)** — запись входного потока команд в append-only
      WAL (`Journal`): собственный бинарный формат с varint, покадровый CRC32, групповой
      коммит с `fsync`. Обёртка `PersistentClob` журналирует команду write-ahead — durable
      до возврата событий.
- [x] **Реплей** — восстановление состояния переподачей журнала в свежий `Clob`
      (`PersistentClob::open`); за счёт детерминизма книга, `order_id` и `seq` воспроизводятся
      точно. Битый хвост от прерванной записи отсекается по CRC. Горячий резерв (реплика) —
      тем же механизмом чтения потока команд.
- [x] **Снимки (snapshots)** состояния книги для ускорения восстановления (`checkpoint()`
      пишет снимок полного состояния и ротирует журнал; `open` грузит снимок и переигрывает
      только хвост журнала; согласование идемпотентно по `seq`, чекпойнт крэш-безопасен). *(фаза 2 v0.3)*
- [x] Версионирование формата: журнал — `magic "CLBW"` + версия в заголовке сегмента;
      снимки — `magic "CLBS"` + версия, общий кадр с CRC32.
